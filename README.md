📊 EDA of Student Performance
📁 Project Overview
This project analyzes student performance data to uncover patterns and insights.

The goal is to understand how factors like gender, lunch type, parental education, and test preparation impact student scores.

📂 Dataset
Source: [e.g., Kaggle, UCI Repository, or custom]

Features:

gender, race/ethnicity, parental level of education, lunch, test preparation course, math score, reading score, writing score

A new column AVG was added to compute average scores.

🔍 Objectives
Perform data cleaning and preprocessing.

Visualize distributions and relationships between categorical and numerical variables.

Use plots like histograms, KDE plots, and heatmaps.

Identify key trends and correlations.

📊 Visualizations Used
Histograms: Score distributions by gender and lunch type

Boxplots: Score comparisons across demographic groups

Heatmap: Correlation matrix of numerical features

Bar plots: Grouped means and counts

🧹 Tools and Libraries
Python (Pandas, Matplotlib, Seaborn)

Jupyter Notebook

Scikit-learn (if ML is used later)

🧠 Key Insights
Females generally perform better in reading and writing.

Students with standard lunch tend to score higher.

Test preparation shows a positive impact on scores.
